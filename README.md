# 🎡 Roleta Premiada - Feirão Casa & Prêmios

Aplicação web interativa, moderna e responsiva pronta para o evento de imóveis.

## 🌟 Destaques da Aplicação
- **Prêmios configurados sob medida**:
  - Air Fryer
  - Ventilador Turbo
  - Liquidificador
  - Vale-Compras
  - Vale-Combustível
  - Kit Churrasco
  - Pix Premiado
  - Jogo de Panelas
- **Efeitos de Som & Celebração**:
  - Tique-tique sonoro realista gerado dinamicamente via sintetizador Web Audio.
  - Fanfarra musical triunfante na vitória.
  - Chuva de confetes com física e partículas em tela inteira.
- **Painel do Feirão**:
  - Campo para digitar o **Nome do Cliente / Unidade / Protocolo**.
  - Histórico em tempo real de quem ganhou cada prêmio com horário.
  - Botão para **Exportar Relatório em CSV/Excel** de todos os sorteios do dia.
  - Botão de **Tela Cheia** ideal para projetores e TVs no estande.
- **Gerenciador de Prêmios**:
  - Altere nomes, cores, adicione novos prêmios ou defina "pesos/probabilidades".
  - Opção para remover automaticamente da roleta o prêmio que já foi sorteado.

## 🚀 Como Executar
1. Basta abrir o arquivo `index.html` em qualquer navegador (Chrome, Safari, Edge):
   ```bash
   open index.html
   ```
2. Ou rodar um servidor local se preferir:
   ```bash
   python3 -m http.server 8080
   ```
   e acessar `http://localhost:8080` no navegador.
